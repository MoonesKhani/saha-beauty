# سالن زیبایی سها

لندینگ فارسی و راست‌به‌چپ سها؛ اطلاعات سالن، خدمات و مسیرهای تماس در قالب موجود حفظ شده‌اند.

## اجرای محلی

از ریشه مخزن اجرا کنید:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

نصب بسته یا ساخت جداگانه لازم نیست. محیط به دسترسی به شبکه توزیع محتوای کتابخانه‌های موجود نیاز دارد.

## ساختار

- `index.html`: خروجی بسته‌بندی‌شده شامل قالب، فونت‌های موجود و منطق تعامل‌های صفحه؛ داده قالب در برچسب `__bundler/template` به‌صورت رشته JSON است. هنگام ویرایش، اعتبار JSON و رفتار بارگذار باید حفظ شود.
- `assets/saha-premium.css`: رنگ‌ها، تایپوگرافی، ترکیب‌بندی واکنش‌گرا، کارت‌ها و دکمه‌های منتخب شیشه‌ای.
- `assets/saha-premium.js`: شکوفه‌افشانی یک‌باره، حرکت اسکرولی، نمایش تدریجی و کنترل توقف حرکت؛ بدون کتابخانه جدید.
- `assets/saha-cinematic-hero*.webp`: تصویر تزئینی تولیدشده و بهینه‌شده برای موبایل و دسکتاپ؛ این تصویر، نمونه‌کار واقعی سالن نیست.
- `assets/saha-blossoms.svg`: تصویرسازی اختصاصی گل و بافت پیوسته زمینه.

نظر مشتری، مدرک، قیمت و نمونه‌کار واقعی جدیدی ساخته نشده است؛ جایگاه‌های موجود با توضیح مشخص نگهداری شده‌اند. راهنمای انتخاب رنگ نیز بر پایه گزینه‌های موجود است و تشخیص یا تحلیل هوش مصنوعی نیست.

پیش از انتشار، موبایل و دسکتاپ، کاهش حرکت، کنترل صفحه‌کلید، مسیر رزرو و تماس، پسندها، پکیج‌ها، رنگ‌ها و شکل‌گیری گلبرگ‌ها بررسی شوند. تنظیمات دامنه و فایل `CNAME` بخشی از بازطراحی نیستند.

## آزمون رفتاری

با وجود بسته توسعه `playwright` و مرورگر Chromium، سرور محلی را اجرا کرده و در ترمینال دوم بزنید:

```sh
python3 tests/smoke_test.py
```

نشانی سرور با متغیر `SAHA_TEST_URL` و مسیر مرورگر با `SAHA_CHROMIUM` قابل تغییر است. آزمون چهار اندازه صفحه، بارگذاری تصویر، انیمیشن یک‌باره، توقف حرکت، تمام بخش‌های خدمات، پکیج‌ها، پسندهای ذخیره‌شده، راهنمای رنگ، تماس، صفحه‌کلید و کاهش حرکت را بررسی می‌کند. گزارش و تصویرهای موقت در `/tmp` ذخیره می‌شوند.
